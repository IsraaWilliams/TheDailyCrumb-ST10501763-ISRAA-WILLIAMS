### Project Overview
The Daily Crumb is a responsive artisan bakery website for 3 Cape Town locations: Woodstock, Claremont, Sea Point. The site allows customers to browse custom cakes, sourdough breads, and pastries, and submit enquiry forms for orders.

### Features Implemented
- 5 Responsive Pages: index.html, about.html, products.html, enquiry.html, contact.html
- Responsive Design: 375px mobile, 768px tablet, 1920px desktop
- Hamburger menu with JavaScript
- Product gallery with lightbox
- Enquiry form with JavaScript validation (inline errors)
- SEO: meta description, Open Graph, semantic HTML
- Performance: optimized images with srcset (hero-400.jpg, hero-800.png, hero-1200.png)
